# Peter Vintage — Website Text

This file contains every editable piece of copy on the site (headlines, paragraphs,
button labels, testimonials, captions). Edit the text after any `[id]` tag and send
the file back — the ID tells me exactly where it goes in the HTML, so nothing gets
mismatched even if two lines end up saying the same thing.

**Please don't**:
- delete or rename the `[id]` tags — they're the map back into the code.
- add/remove whole sections here — if you want a new section, tell me separately.

**Not included** (functional, not copy): navigation URLs, image files, stats/percentages
that come from the shop's actual sales data (listing count, ratings, language %,
size/colour/condition breakdowns) — those get refreshed from the data, not hand-edited.
Image alt-text (accessibility descriptions) is also left out; say if you'd like it in.
